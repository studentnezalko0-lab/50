# Release Notes

## 1.0.0 — Оқу жобасының құжаттамалық нұ��қасы

### Қосылған мүмкіндіктер

- Онлайн тамақ жеткізу жүйесінің мақсаты мен пайдаланушылары сипатталды.
- REST API үшін OpenAPI 3.0 спецификациясының үлгісі дайындалды.
- Пайдаланушы нұсқаулығы құрылды.
- Талаптарды бақылау матрицасы (RTM) жасалды.
- Финалдық валидация есебінің үлгісі дайындалды.
- Жоба құрылымы мен іске қосу командалары README құжатына енгізілді.

### Тексеруді қажет ететін мүмкіндіктер

- Тіркелу және авторизация.
- Мейрамханалар мен тағамдар каталогы.
- Тапсырыс жасау және тапсырыс мәртебесін басқару.
- Онлайн төлем интеграциясы.
- Курьердің GPS орналасуын бақылау.
- Қауіпсіздік пен жүктеме талаптары.

### Шектеулер

Бұл релиз құжаттамалық және оқу мақсатындағы нұсқа болып табылады. Нақты өндірістік релиз деп есептелмейді.

### Келесі қадамдар

- API маршруттарын іске асыру.
- PostgreSQL деректер қорымен интеграция жасау.
- Unit және интеграциялық тесттерді қосу.
- CI workflow арқылы автоматты тексеруді іске қосу.
- Қауіпсіздік пен өнімділік нәтижелерін тіркеу.
