# REST API құжаттамасы

## Жалпы ақпарат

API форматы — JSON. Сұраныстар мен жауаптар UTF-8 кодтауын қолданады.

Жергілікті сервердің негізгі мекенжайы:

`http://localhost:8000`

## Эндпоинттер

| Әдіс | Эндпоинт | Мақсаты |
| --- | --- | --- |
| GET | `/health` | Жүйенің жұмыс күйін тексеру |
| POST | `/users` | Пайдаланушыны тіркеу |
| GET | `/users/{user_id}` | Пайдаланушыны алу |
| GET | `/restaurants` | Мейрамханалар тізімін алу |
| POST | `/orders` | Тапсырыс жасау |

## Мысал: пайдаланушыны тіркеу

### Сұраныс

```json
{
  "full_name": "Асан",
  "email": "asan@example.com"
}
```

### Күтілетін жауап мысалы

```json
{
  "user_id": 1,
  "full_name": "Асан",
  "email": "asan@example.com"
}
```

HTTP мәртебесі: `201 Created`.

## Мысал: тапсырыс рәсімдеу

### Сұраныс

```json
{
  "user_id": 1,
  "items": [
    {
      "product_id": 10,
      "quantity": 2
    }
  ]
}
```

### Күтілетін жауап мысалы

```json
{
  "order_id": 1001,
  "user_id": 1,
  "status": "NEW"
}
```

HTTP мәртебесі: `201 Created`.

## Қателер

- `400 Bad Request` — сұраныс деректері дұрыс емес.
- `404 Not Found` — қажетті ресурс табылмады.
- `409 Conflict` — ресурс бұрыннан бар немесе операция қайшылық тудырады.
- `500 Internal Server Error` — серверде күтпеген қате пайда болды.

## Қауіпсіздік

Өндірістік ортада авторизация, рөлдер бойынша қолжетімділікті басқару, HTTPS және енгізілетін деректерді сервер жағында тексеру қарастырылуы тиіс. Төлем карточкасының толық реквизиттері мен құпиясөздер логтарға жазылмауы керек.
