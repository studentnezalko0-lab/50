# Пайдаланушы нұсқаулығы

## 1. Жүйеге кіру

1. Қосымшаны немесе веб-сайтты ашыңыз.
2. Тіркелу формасына аты-жөніңізді және электрондық поштаңызды енгізіңіз.
3. Тіркелу батырмасын басыңыз.
4. Қолданбада авторизация іске асырылған болса, тіркелгі деректерімен жүйеге кіріңіз.

## 2. Тағам таңдау

1. Мейрамханалар тізімін ашыңыз.
2. Қажетті мейрамхананы таңдаңыз.
3. Мәзірден тағамдарды қараңыз.
4. Қажетті тағамдарды себетке қосыңыз.

## 3. Тапсырыс рәсімдеу

1. Себетті ашыңыз.
2. Тағамдар мен олардың санын тексеріңіз.
3. Жеткізу мекенжайын енгізіңіз.
4. Тапсырысты растаңыз.
5. Төлем мүмкіндігі іске асырылған болса, қолжетімді төлем әдісін таңдаңыз.

## 4. Тапсырыс мәртебесін бақылау

Тапсырыс мәртебесі жүйеде көрсетілген жағдайда, оны тапсырыстар бөлімінен тексеріңіз. GPS арқылы курьерді бақылау мүмкіндігі іске асырылып, рұқсат берілгеннен кейін ғана қолжетімді болады.

## 5. Қате туындаған жағдайда

1. Енгізілген деректердің дұрыстығын тексеріңіз.
2. Интернет байланысын тексеріңіз.
3. Қате туралы хабарламаны сақтап алыңыз.
4. Мәселе қайталанса, жүйелік әкімшіге хабарласыңыз.

## 6. Қауіпсіздік ережелері

- Құпиясөзді басқа адамдарға бермеңіз.
- Төлем деректерін бөгде адамдарға жібермеңіз.
- Ортақ компьютерде жұмысты аяқтағаннан кейін жүйеден шығыңыз.
- Күдікті әрекеттер байқалса, әкімшіге хабарлаңыз.
