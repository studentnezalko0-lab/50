# Онлайн тамақ жеткізу жүйесі

## Жоба туралы

Бұл жоба пайдаланушыларға мейрамханалардан тамақ таңдауға, тапсырыс рәсімдеуге, онлайн төлем жасауға және курьердің орналасқан жерін бақылауға мүмкіндік беретін веб және мобильді қосымшаны әзірлеуге арналған.

Жоба бағдарламалық қамтамасыз ету талаптарын талдау, архитектураны жобалау, API әзірлеу, тестілеу және финалдық валидация кезеңдерін қамтиды.

## Негізгі мүмкіндіктер

- Пайдаланушыны тіркеу және авторизациялау.
- Мейрамханалар мен тағамдар каталогын қарау.
- Себетке тағам қосу және тапсырыс рәсімдеу.
- Онлайн төлем жасау.
- Тапсырыс мәртебесін бақылау.
- Курьердің орналасқан жерін GPS арқылы көрсету.
- Тапсырыс тарихын қарау.
- Мейрамхана әкімшісінің тапсырыстарды басқаруы.
- Пайдаланушы пікірлері мен бағаларын қабылдау.

## Пайдаланушылар

- Тұтынушы — тағам таңдайды, тапсырыс береді және төлем жасайды.
- Курьер — тапсырысты қабылдайды және жеткізу мәртебесін жаңартады.
- Мейрамхана әкімшісі — мәзірді және тапсырыстарды басқарады.
- Жүйелік әкімші — пайдаланушылар мен жүйенің жұмысын басқарады.

## Технологиялар

- Backend: Python, FastAPI.
- API спецификациясы: OpenAPI 3.0.
- Деректер қоры: PostgreSQL.
- Контейнерлеу: Docker және Docker Compose.
- Тестілеу: pytest, HTTPX.
- CI/CD: GitHub Actions.
- Код сапасы: Ruff және Black.

Бұл технологиялар жобаның жоспарланған технологиялық стегін сипаттайды. Олардың барлығы біртұтас жұмыс істейтін өнімге біріктірілгені жеке тексерілуі керек.

## Жүйенің функционалдық емес талаптары

- API сұраныстарының 95%-ы келісілген жүктеме жағдайында 300 мс-тан аспайтын уақытта орындалуы тиіс.
- Негізгі экран 3G желісінде 2 секунд ішінде жүктелуі тиіс.
- Жүйенің жылдық қолжетімділігі 99,9% болуы тиіс.
- Құпия деректер қорғалған түрде сақталуы тиіс.
- Қателер журналында парольдер, төлем деректері және басқа құпия ақпарат сақталмауы тиіс.

Бұл көрсеткіштер — тексеруге арналған мақсатты талаптар; олардың орындалуы жүктеме және қауіпсіздік тестілерімен расталуы қажет.

## Жобаны іске қосу

Жергілікті ортада Docker және Docker Compose орнатылған болуы керек.

```bash
docker compose up --build
```

Қолданба іске қосылғаннан кейін FastAPI сервері 8000 порты арқылы қолжетімді болады.

- Негізгі бет: http://localhost:8000
- Swagger API құжаты: http://localhost:8000/docs
- OpenAPI JSON: http://localhost:8000/openapi.json

Бұл мекенжайлар FastAPI қолданбасы тиісті маршруттармен іске қосылған жағдайда қолданылады.

## Тестілеу

Тәуелділіктер орнатылғаннан кейін:

```bash
pytest -v
pytest --cov=main --cov-report=term-missing
```

Код стилін тексеру:

```bash
ruff check .
black --check .
```

Тесттердің өтуі, coverage көрсеткіші және линтер нәтижелері нақты орындалған командалардың шығысымен расталуы тиіс.

## Құжаттама

- `docs/API.md` — API эндпоинттері
- `openapi.yaml` — OpenAPI спецификациясы
- `docs/USER_GUIDE.md` — пайдаланушы нұсқаулығы
- `docs/RTM.md` — талаптардың трассировка матрицасы
- `docs/VALIDATION_REPORT.md` — финалдық валидация есебі
- `docs/RELEASE_NOTES.md` — релиз өзгерістері

## Жоба мәртебесі

Жоба оқу және практикалық жұмыс мақсатында әзірленеді. Финалдық дайындық мәртебесі функционалдық, интеграциялық, қауіпсіздік және өнімділік тестілерінің нәтижелері бойынша анықталады.
